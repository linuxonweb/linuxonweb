Commands and package behavior

This console runs as root inside its own guest. Try apk update, apk add python3, then python3 -c 'print(2 ** 20)'. Use apk del python3 to remove it.

The repository targets wasm32-unknown-linux-musl; ordinary x86 or ARM Alpine packages cannot run here. Python supports files, JSON, compression, hashing, SSL contexts, sockets, threads and os.posix_spawn. subprocess.Popen, mmap and ctypes are unavailable. Node.js is not yet ported.

The home folder is separate from the full desktop's home. Stop this console before opening another copy.
